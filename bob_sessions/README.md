# Bob Sessions

This folder holds logs/notes from IBM Bob AI-pair-programming sessions used while building CodeGuardian AI (see [`../docs/IBM_BOB_USAGE.md`](../docs/IBM_BOB_USAGE.md) for the usage summary).

Suggested convention for adding a new session log:

```
bob_sessions/
└── 2026-09-27-architecture-planning.md
└── 2026-09-28-frontend-scaffold.md
└── 2026-09-29-security-prompt-tuning.md
```

Each log should briefly capture: the mode used (Plan / Agent / Ask), the goal of the session, and any notable diffs accepted or rejected.
